harness.exe — native agent loop.

USAGE:
    harness.exe --help
    harness.exe --help-tools
    harness.exe --version
    harness.exe [--cwd <path>] [--api-key <key>] [--conf <path>] --prompt "<user prompt>"
    harness.exe [--cwd <path>] [--api-key <key>] [--conf <path>] --prompt-file <path to prompt file>
    harness.exe [--cwd <path>] [--api-key <key>] --dump "<path to dump file>"
    harness.exe --conf-new "<path to new conf file>"

FLAGS:
    --help
        Print this help and exit with code 0.

    --help-tools
        Print the description of all tools and their configuration parameters and exit with code 0.

    --version
        Print the application version and exit with code 0.

    --conf <path>
        Path to harness.json5. Optional. Default: <process-cwd>/harness.json5
        (the current working directory of the process, not settings.cwd).
        Inside it, agent.config may be an agent file or a folder
        of agent files (you will be asked to choose).
        Cannot be combined with --conf-new or --dump.

    --prompt "<user prompt>"
        Start a new session with this user prompt.

    --prompt-file <path>
        Start a new session; the user prompt is read from the file (UTF-8).

    --dump "<path to dump file>"
        Continue a session from a dump file. The prompt is taken from dump
        history; --prompt is not used.
        Configuration is taken from the dump file; --conf cannot be used
        with --dump.

    --cwd <path>
        Workspace root override. Overrides 'cwd' from harness.json5 (or dump).
        A relative path is resolved against the directory of the working conf file:
        parent(--conf) for a new session, the directory of the dump settings for --dump.
        The final value is absolute and normalized.
        Can only be used with --prompt, --prompt-file or --dump.

    --api-key <key>
        API-key override. A literal key or a path to a UTF-8 file whose trimmed
        contents are the key. A relative file path is resolved against the final cwd.
        Overrides any api-key from the model file. If no key is configured and this
        flag is absent, harness asks for the key in the console.
        Can only be used with --prompt, --prompt-file or --dump.

    --conf-new "<path to new conf file>"
        Write a full commented JSON5 template to the path and exit.
        Does not start the loop, the agent or any network calls.
        Fails if the file already exists. Creates missing parent directories.

RULES:
    --prompt, --prompt-file, --dump and --conf-new are mutually exclusive.
    One of --prompt, --prompt-file, --dump or --conf-new is required.
    --conf cannot be used with --dump (configuration is taken from the dump file).
