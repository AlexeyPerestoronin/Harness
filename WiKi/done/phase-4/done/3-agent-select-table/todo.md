# Задача на разработку: Таблица агентов при выборе из каталога
Когда перед циклом пользователю предлагают выбрать агента из папки, печатать в консоль выровненную таблицу, а не список `N) Vendor Name (file.json5)`.

Зачем: по номеру сейчас не видно ни цены, ни лимитов модели.

Ожидаемый результат (моноширинная консоль, колонки одной ширины, разделитель как в примере):

```text
Available agents in C:\MyLife\Harness\harness/agents:
| №  | Vendor   | Model                 | Cost (Input/Output/Cached) | Limits (Tokens/RPM/TPM/RPD) |
|----|----------|-----------------------|----------------------------|-----------------------------|
| 1  | Claude   | Claude Sonnet 5.5     | 2.00 / 10.00 / 0.10        | 500000 / -1 / -1 / -1       |
| 2  | DeepSeek | DeepSeek-Flash        | 0.15 / 0.60 / 0.003        | -1 / -1 / -1 / -1           |
| 13 | AliBaba  | Qwen-Turbo            | 0.05 / 0.20 / -1           | -1 / 1500 / 1000000 / -1    |

Select agent [1-13]:
```

Ширины в примере иллюстративные. Считать их по фактическим строкам, не хардкодить под 13 моделей.

## Функциональные требования
### 1. Когда рисовать таблицу
1. Кандидатов 2 и больше — вместо нынешнего нумерованного списка с именем файла печатать таблицу, затем пустую строку, затем прежний промпт `Select agent [1-N]: ` (без перевода строки перед вводом, как сейчас).
2. Ровно один кандидат — поведение не менять: одна строка `Agent: <vendor> <name> (<file>)`, вопроса нет, таблицы нет.
3. Пустой список по-прежнему ошибка `agent was not selected` до печати таблицы.
4. Правила ввода не менять: номер с 1, не больше 3 попыток, мусор — повтор, пустая строка и EOF — `agent was not selected`.
5. Строки `skipped '...'` по-прежнему пишет сканер в stderr. Этот модуль их не форматирует и не прячет.
6. Писать таблицу туда же, куда сейчас пишется список (stdout / переданный `Write`). В `log.md` таблицу не дублировать.

### 2. Откуда числа
Не открывать json5 и не ходить в `conf` за повторным разбором. Брать уже заполненные поля `AgentCandidate`:

- колонка Vendor — `vendor`
- колонка Model — `name`
- Cost — `input_price`, `output_price`, `cached_price`
- Limits — `token_limit`, `rpm`, `tpm`, `rpd` (это лимиты файла модели, не сессионные лимиты `harness.json5`)

Если какого-то из этих полей нет в структуре — остановись и спроси. Не парси файл сам и не подставляй заглушки.

Порядок строк и номера — порядок слайса, который уже пришёл (сортировка по имени файла снаружи). Не пересортировывать по vendor.

Имя файла в таблице не показывать. Колонку USD-лимита не добавлять: в заголовке её нет.

Заголовок лимитов именно `Limits (Tokens/RPM/TPM/RPD)`. Не `TMP`.

### 3. Формат ячеек
1. Цена `-1` печатается как `-1`, не как `free` и не как `-1.00`.
2. Остальные цены: без экспоненты; минимум два знака после запятой (`2.00`, `10.00`, `0.10`, `0.60`, `6.00`); если дробная часть длиннее двух знаков — не округлять (`0.003`, `0.014`, `0.025`, `0.0375`, `0.375`, `1.875`).
3. Три цены в одной ячейке через ` / ` (пробел, слэш, пробел).
4. Четыре лимита — целые как в настройках, без разделителей тысяч, тоже через ` / `. Пример: `-1 / 1500 / 1000000 / -1`.
5. Таблица: ведущая и замыкающая `|`, колонки дополнены пробелами до ширины заголовка или самого широкого значения. Строка-разделитель из `-` по ширине колонки, как в примере (`|----|`). Внешняя библиотека таблиц не нужна.
6. Первая строка по-прежнему `Available agents in {dir}:`, каталог — parent первого файла, как сейчас.

### 4. Комментарий модуля
В шапке `agent_select.rs` сейчас написано `agent-setting.config`. Ключ давно называется `agent.config`. Поправить комментарий, логику загрузки не трогать.

## Scope
- `crates/harness/src/agent_select.rs`

Не менять: `crates/conf/**`, `harness/agents/**`, `crates/harness/src/agent_loop.rs`, `crates/harness/src/agents/**`, README, CLI.

## Проверка корректности решения
1. `cargo test --workspace`. Сеть не нужна.
2. Юнит-тесты `choose_from` с подменой `BufRead`/`Write` (функция уже принимает их):
   - два кандидата с разными ценами и лимитами → в выводе есть заголовок `Cost (Input/Output/Cached)`, заголовок `Limits (Tokens/RPM/TPM/RPD)`, оба vendor/model, отформатированные цены (`0.003` не стал `0.00`, `-1` не стал `free`), промпт `Select agent [1-2]: `; имени файла в таблице нет;
   - строки таблицы одной ширины (каждая строка с `|` равна по длине заголовку, либо колонки дополнены так, что разделитель совпадает по колонкам — зафиксируй в тесте выбранный критерий);
   - неверный ввод, затем `1` → индекс 0; три мусорных ввода → ошибка `agent was not selected`; EOF → та же ошибка;
   - один кандидат → нет `Select agent`, есть прежняя строка `Agent: ...`, нет таблицы.
3. Ручной прогон не обязателен. Если будешь смотреть глазами — прервись на промпте, запрос в API не отправляй.
