# Что сделать вручную

1. Пересобрать бинарник и запускать уже его, не старый `harness.exe` из корня репозитория:
   `cargo build --release -p harness`
   Бинарник: `target/release/harness.exe`.
2. Повторить сессию DeepSeek (можно `--dump` того прогона, где попытки падали на ~30 с). Секундомер должен уйти дальше `0 min 30 sec` без `error decoding response body`.
3. Если запрос всё же упадёт, в строке `⚠️ N-attempt request failed:` теперь будет причина после двоеточия — пришлите её.
