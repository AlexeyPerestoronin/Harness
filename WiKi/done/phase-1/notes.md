# Задача
Необходимо проанализировать кода данного репозитория и сформировать задачи на разработку по следующим пунктам улучшения:
1. Переписать на по-английски (EN) все tools descriptions.
2. Объединить логику `crates\tools\src\fs.rs` + `crates\tools\src\search.rs` в одном модуле так как вся эта логика связана с файловой системой + добавить 2 новых инструмента `find_file_by_str`, `find_files_by_regex`.
3. Удалить модуль `crates\tools\src\sandbox.rs` + `crates\tools\src\meta.rs` → лишняя логика от которой лучше избавиться → объединённый fs tools должны персонально владеть таким вспомогательными параметрами как `available-dirs`, `available-file-extensions`, `extra-scope`.
4. Подключить github-actions для сборки на windows и linux при каждом push в ветку master.
5. Добавить README.<en|ru>.md
6. Добавить поддержку `claude-sonnet-5-5` от Claude.
7. Добавить возможность запуска в качестве сервера.

## Особые указания:
1. Задачи можно объединять, если это целесообразно, но общая последовательность должна сохраняться.
2. Для каждой задачи должна быть создана уникальная папка `WiKi/todo/phase-1/<task-number>-<task-name>` внутри которой необходимо создать `todo.md`, где и описать задачу.
3. Шаблон для каждого `todo.md` см. в `WiKi/harness/templates/development.md`
4. Также в папке задачи необходимо создать `harness.json5` достаточный для выполнения задачи.
