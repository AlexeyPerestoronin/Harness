# Ручные проверки

Автоматические проверки выполнены:

- `cargo build --workspace`
- `cargo test -p cli-harness -p agent-loop`

Остались ручные сценарии из todo.md:

1. **Консольный режим, выбор агента**
   - Конфигурация с `agent.config = directory` (несколько кандидатов).
   - Запуск `harness --conf ... --prompt "..."`.
   - Ожидается таблица `Available agents in ...` и запрос `Select agent [1-N]:`.

2. **Консольный режим, запрос ключа**
   - Конфигурация с `agent.config = file` и пустым `api-key` в модели.
   - Запуск `harness --conf ... --prompt "..."`.
   - Ожидается `Enter API key for <Vendor> <Model>:`; пустой ввод завершается ошибкой.

3. **Серверный режим, выбор агента**
   - Конфигурация с `agent.config = directory` (несколько кандидатов).
   - `POST /api/v1/run`.
   - Ожидается `pendingInput` с промптом выбора агента.

4. **Серверный режим, отмена**
   - В состоянии `pendingInput` выбора агента вызвать `POST /stop`.
   - Ожидается терминальное состояние `stopped` (не `failed`).

5. **Тексты промптов**
   - Промпты выбора агента и API-ключа не изменились относительно прежней версии.
