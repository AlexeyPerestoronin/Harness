# Ручная проверка

Автоматические проверки выполнены:

- `cargo build --workspace` — успех, без warnings.
- `cargo test -p agent-loop` — успех, 8 тестов.

Для ручной проверки с реальным API-ключом:

1. Запустите консольную агентскую сессию с реальным API-ключом и не-streaming моделью.
2. Дождитесь ответа модели.
3. Убедитесь, что в консоли строка `response waiting time: X min Y sec` обновляется каждую секунду и показывает фактически прошедшее время ожидания (а не `0 min 0 sec`).
4. Убедитесь, что в файле `log.md` служебная строка `response waiting time:` отсутствует (она пишется с `write_log = false`).
