# Запрос на рефакторинг кодовой базы по факту завершения задач 6 фазы разработки

Специальные цели рефакторинга:
1. уменьшить количество кода там где это возможно
2. уменьшить связность между отдельными компонентами там, где это возможно
3. актуализировать документацию:
    - оставить только английский язык;
    - добавить в README.md информацию об архитектуре приложения, используемых технологиях и базовых pipeline работы пользователя

# Баги выявленные в процессе тестирования PO
## Bug with request time-counter
После изменений request time-counter работает не правильно: в console лог-output агентской сессии при ожидании запроса счётчик не отмеряет секунды до ожидания ответа, а показывает всегда 0min 0sec (либо 0min 1sec):
```txt
## Iteration №4
Usage:
- time = 0 min 9 sec
- tokens = 5454
- USD approximated = 0.004468
response waiting time: 0 min 0 sec response
```
> вообще выглядит так, словно таймер отсчитывается но выводится в консоль некорректно из-за того, что весь стек теперь асинхронный.

## --serve with serve messages
Запуск cli-harness в режиме сервера должен выводить при запуске справочную информацию о параметрах запуска.

## Free port detection
В ситуации, когда целевой порт для запуска сервера занят, необходимо последовательно искать первый свободный с шагом +1 и выводить статусную информацию о процессе поиска.

## REST-API.help.md
Необходимо написать полноценную инструкцию по API для сервера в виде отдельного файла.
Рассмотреть использование специальных нотаций, например PostMan.

# Дополнительные указания:
Последней задаче в цикле рефакторинга должна быть задача на очищение кода от всего, что не требуется для работы на "боевом посту", например unit-тестов.
