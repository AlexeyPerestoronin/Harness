# Задача на исправление: xai request error
Необходимо исправить ошибку запроса к вендору xai:
```
HTTP 415: Expected request with `Content-Type: application/json
```

Для проверки корректности решения, скорее всего придётся написать несколько unit-тестов, в которых будет необходимо делать запросы к grok-4.6, поэтому я подготовил тестовый API-ключ, который ты найдёшь в файле API_KEY_XAI в корне репозитория:
    - на время проверки можешь захарткодить его в unit-тест, но в конце удали (пользователь должен вводить его через консоль при самостоятельном запуске теста)

Дополнительная информация:
1. ошибка появилась после решения задачи - WiKi\todo\phase-3\5-vendor-request-rate-limits\todo.md
2. ошибка появляется при запуске агентского цикла с Grok-4.6
3. также необходимо обратить внимание на неиспользуемую функцию `wait_rate_limit` (crates\harness\src\vendor_request.rs) → если она не нужна нужно удалить
