# Задача на разработку: CLI-команда `--version`
Добавить в `harness.exe` команду `--version`, которая печатает текущую версию приложения и завершается с кодом 0.

Зачем: нужно видеть, какая сборка запущена (в том числе при сопоставлении с `scripts/build.py` и артефактами CI, где имя файла содержит версию).

Ожидаемый результат: `harness.exe --version` печатает одну строку `harness <X.Y.Z>`, например `harness 1.1.0`, код возврата 0; конфигурация, ключи и сеть не нужны.

## Функциональные требования
1. Источник версии — единственный: `[workspace.package].version` корневого `Cargo.toml`. Crate `harness` уже наследует его (`version.workspace = true`), в коде читать через `env!("CARGO_PKG_VERSION")` — **без** хардкода и без чтения файлов в рантайме.
2. `crates/harness/src/cli.rs`: новый вариант `CliAction::Version` и флаг `--version` (без значения; короткий алиас `-V` **не** добавлять). Приоритет такой же, как у `--help`: флаг срабатывает независимо от остальных (`--version --prompt x` → `Version`). Приоритеты между флагами справки: если указано несколько из `--help`, `--help-tools` (если уже добавлен), `--version`, порядок такой: `--help` → `--help-tools` → `--version` (побеждает первый из присутствующих).
3. Формат строки: `harness <version>` + перевод строки, вывод в stdout. Строку формирует отдельная функция (например `version_line() -> String`) для тестирования.
4. `crates/harness/src/main.rs`: ветка `CliAction::Version` печатает строку и возвращает успех.
5. `crates/harness/help.txt`: добавить в `USAGE` строку `harness.exe --version`, в `FLAGS` — `--version` с описанием `Print the application version and exit with code 0.`
6. Другие задачи могли менять `cli.rs`, `main.rs`, `help.txt` (например `--help-tools`) — перечитай файлы перед правкой и не ломай существующее.

## Scope
- `crates/harness/src/cli.rs`
- `crates/harness/src/main.rs`
- `crates/harness/help.txt`

Корневой `Cargo.toml` — только чтение (версию не менять).

## Проверка корректности решения
1. `cargo test --workspace`.
2. Тесты в `cli.rs`: `--version` → `Version`; `--version --prompt x` → `Version`; `--help --version` → `Help`; `version_line()` равен `format!("harness {}", env!("CARGO_PKG_VERSION"))`, содержит три числовых компонента через точку; `HELP` содержит `--version`.
3. Ручной шаг: `target\debug\harness.exe --version` печатает версию из корневого `Cargo.toml`, код возврата 0.
