# Задачи на будущее

## Provide additions settings for agents
Добавить в конфигурационной файл агентов опциональный параметр `additions` в котором будут записываться настройки для агентов, которые носят опциональный и уникальный характер для каждого из агентов.

## Remove AgentKind
Необходимо избавиться от AgentKind (см `crates\conf\src\types.rs`) и всей связанной логике, которая занимает переводом псевдонима имени модели в имя модели, оправляемое в запросе.

Ожидаемый эффект:
1. Во всех файлах конфигурации агентов ключ `name` уже содержит отправляемое имя модели;
2. Добавление новой модели известного вендора не требует перекомпиляции исходного кода.


## Check alive in very long requests
В ситуации, когда агент думает очень долго (больше 3 минут) необходимо добавить како-то механизм проверки того, что ответ находится в процессе подготовки и будет предоставлен, чтобы исключить вероятность бессмысленного бесконечного ожидания.
