# Задачи для 7 фазы разработки:

Основная цель 7 фазы разработки - доработать серверную часть приложения.

## harness.json5 first
`harness.exe` всегда должен описать на какой-то файл конфигурации в любом из режимов работы → если не задан `--conf` и в CWD не лежит `harness.json5` то, необходимо создать `harness.json5`-по-умолчанию в CWD и загрузить уже его.

Важные моменты:
1. создание конфигурации по умолчанию в случае его отсутствия, это, по сути, замаскированный вызов `--conf-new`, после чего файл конфигурации читается в новой, уже успешной, попытке:
   - если файл создать невозможно, то программа запускаться не должна
2. необходимо проверить файл `crates\conf\settings-template.json5` на актуальность и привести его в соответствие со следующими требованиями:
    - в блоке `vars` оставить буквально пару переменных, просто для того, чтобы было понятно, что такое переменные и как ими пользоваться;
    - tools должен быть настроен с минимальным количеством ограничений
3. в коде не должно быть захардкоженных значений на случай отсутствия таковых в файле конфигурации → если в файле чего-то нет, значит программа не запускается с выводом подробного сообщения об ошибке (по идее кода должно стать меньше)
4. В начале цикла, перед первой итерацией необходимо выводить log-информацию о том, какой именно harness.json5 был использован для запуска приложения (т.е. полный путь).

## --serve with serve messages
Запуск cli-harness в режиме сервера должен выводить при запуске справочную информацию о параметрах запуска.

## Free port detection
В ситуации, когда целевой порт для запуска сервера занят, необходимо последовательно искать первый свободный с шагом +1 и выводить статусную информацию о процессе поиска.
