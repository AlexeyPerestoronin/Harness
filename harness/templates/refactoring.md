# Отчёт
Пиши в `note.md` рядом с `todo.md`:

```
# Рефакторинг №-<N>: «суть проблемы»
Описание проблемы:
...

Предлагаемые решения:
Решение №1: ...
Решение №2: ...

Сравнительная таблица:
<критерий | №1 | №2 | ...>

Если решение одно — почему остальные неприемлемы.

# Ваше заключение:
(глава для меня)
```

После отчёта я зафиксирую решение по пунктам — затем рефакторинг.

# Дополнительные указания
1. Краткая сводка — в `result.md` рядом с `todo.md`, формат `было→стало(почему)`.
2. Код не запускай (запускаю сам).
3. Экономь токены: читай минимум необходимого; правки через patch.
4. Без X-Search и web_search, пока не разрешу: сначала запрос в чате — что найти и зачем.
